# TrueRep Privacy Policy

This repository hosts the official Privacy Policy for **TrueRep** (AI Workout & Nutrition Coach).

## Hosted URL
[https://aryann-gd.github.io/truerep-privacy-policy/](https://aryann-gd.github.io/truerep-privacy-policy/)

## Key Architectural Principles
- **0 Accounts Required**: No email, phone number, or password required.
- **100% On-Device AI Vision**: MediaPipe Pose model runs strictly in volatile RAM.
- **0 Cloud Image/Video Uploads**: Camera frames are instantly destroyed after landmark extraction.
- **Local Storage Only**: Workouts, streaks, XP, coins, and levels are persisted solely in the device sandbox.
